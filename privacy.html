Privacy Policy - Agen Misteri

Last updated: November 2026. Back to home page

1. Who we are

Agen Misteri is a personal, non-commercial tool operated by a single individual (the "owner"). It is used only by the owner with the owner's own Google account and YouTube channel. Contact: prabundika@gmail.com.

2. Google user data we access

The app requests one permission: https://www.googleapis.com/auth/youtube.upload. It is used only to upload a video file, with its title, description and tags, as a private video to the owner's own YouTube channel. The app does not read the owner's existing videos, playlists, comments, subscribers, analytics, email, contacts or any other Google data.

3. How data is used

The only Google data the app holds is an OAuth refresh token. It is used solely to obtain short-lived access tokens so that the automated upload described above can run. It is not used for advertising, profiling, analytics or any other purpose.

4. Storage and security

The OAuth credentials are stored only as encrypted secrets in the owner's private GitHub repository settings. They are not copied to any other server, database or third-party service, and are never written into the published videos or logs.

5. Sharing

We do not sell, share, transfer or disclose Google user data to any third party. We do not allow humans to read Google user data except as required by law or with the owner's explicit consent.

6. Google API Services User Data Policy

Agen Misteri's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and your control

Credentials are kept only while the tool is in use. The owner can revoke the app's access at any time at myaccount.google.com/permissions and can delete the stored secrets at any time.

8. Children

The app is not directed to children and does not knowingly collect information from children.

9. Changes

If this policy changes, the updated version will be published on this page with a new date.

10. Ringkasan (Bahasa Indonesia)

Aplikasi ini hanya dipakai oleh pemiliknya untuk mengunggah video buatannya sendiri ke kanal YouTube miliknya, dengan status private. Aplikasi tidak membaca data YouTube lain, tidak membagikan atau menjual data apa pun, dan token akses hanya disimpan sebagai rahasia terenkripsi di repositori GitHub pribadi pemilik. Akses dapat dicabut kapan saja lewat myaccount.google.com/permissions.
